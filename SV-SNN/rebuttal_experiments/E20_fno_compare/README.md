# E20 — FNO vs SV-SNN Comparison

**Purpose.** A same-framework (JAX-GPU) comparison of the data-driven Fourier Neural Operator (FNO) against the physics-informed, data-free SV-SNN, clarifying that they occupy complementary regimes.

**Reviewer comments addressed.** R9.1 / R5.3 (FNO baseline requested).

## Setup

| Item | Detail |
|------|--------|
| Task | Random multi-frequency 2D Poisson on `[0,1]²` (not forced separable) |
| FNO | 4 spectral blocks, modes = 16, width = 32, **4,202,976 params**; `N_train ∈ {64, 256, 1024}`, 100-instance holdout |
| SV-SNN | 16 held-out instances, M = 6, K = 32, **1170 params**, `w_char = k_max`, 5000 epochs, 64×64 grid |
| Seeds | 3 per `N_train` (9 FNO runs); SV-SNN evaluated on 16 instances |

## Key results

| Metric | FNO (`N_train` = 1024) | SV-SNN |
|--------|-----------------------:|-------:|
| Held-out rel L2 (mean) | **1.25e-2** | 4.10e-2 ± 3.04e-2 |
| Parameters | 4,202,976 | **1,170** |
| Labeled (f, u) pairs needed | 1024 | **0** |
| Train/solve time | 32.3 s (one-time) | 5.6 s/instance |
| Single-instance inference | **0.33 ms** | 5.6 s |
| Peak VRAM | ~300 MB | 72–322 MB |

FNO data-efficiency scan (held-out rel L2, 3-seed mean):

| `N_train` | 64 | 256 | 1024 |
|-----------|---:|----:|-----:|
| FNO | 7.3e-2 | 2.2e-2 | 1.25e-2 |

SV-SNN reference: **4.10e-2 ± 3.04e-2** (min 6.2e-3, max 1.27e-1). Data crossover ≈ 128 samples; amortization crossover `Q* ≈ 6` queries (excluding the cost to generate training data).

## Conclusions

- The two are complementary paradigms: FNO needs labeled data; SV-SNN needs none.
- FNO wins with ≥256–1024 training samples and many repeated queries; SV-SNN wins with zero/scarce data, few queries, and ~3590× fewer parameters.
- FNO's amortization advantage assumes a pre-existing labeled dataset.
