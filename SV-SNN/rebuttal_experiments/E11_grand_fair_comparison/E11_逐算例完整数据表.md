# E11 逐算例完整数据表（全指标，无省略）

> 本文件逐算例、逐方法、逐预算列出 E11 的**全部**指标，数值逐项取自 `saved_data/summary_meanstd.csv`（83 组 / 245 次运行 / 3 seeds / 0 失败）。
> 不做任何取舍。配套的结论性分析见 `E11_完整数据汇总分析.md`，本表是其**完整数据底表**。

## 列含义
- **参数**：`total_params`（实际计数）；**目标**：matched 预算下要对齐的 SV-SNN 参数量 `target_params`。
- **±10%**：matched 是否落入 SV-SNN 参数 ±10%（`matched_within_tol`）。
- **best L2 / final L2**：相对 L2 误差，`均值 ± 标准差`（3 seeds）；**min** 为 3 种子最优单次。
- **墙钟(s)**：`wall_clock_train_sec` 均值；**每100步(ms)**：`ms_per_100_epoch` 均值。
- **峰值显存(MB)**：`peak_gpu_mem_mb`（子进程隔离）；**推理(ms)**：`inference_time_ms`（"—"=单体算例未统一抓取）。
- **配点**：`n_collocation`（可分离网格法用网格点，逐点法用散点，为各方法原生采样）。
- 行序固定：SV-SNN → SPINN(matched/rich) → SIREN(m/r) → FourierPINN(m/r) → PINN(m/r) →（经典谱）。
