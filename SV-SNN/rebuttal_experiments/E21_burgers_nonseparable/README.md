# E21 — Non-Separable Burgers Shock (Same-Paradigm Comparison)

**Purpose.** Tackle a fully non-separable viscous Burgers problem with a shock, and fairly compare *temporal representations* on a shared spectral-Galerkin substrate (a "same-paradigm" comparison). Also reports the pure-residual track, where SV-SNN — like all neural methods — has clear limits.

**Reviewer comments addressed.** Need for a non-separable / shock case and an honest methodology statement (not assigned a single reviewer number).

## Setup

| Item | Detail |
|------|--------|
| PDE | `u_t + u·u_x = ν·u_xx`, `ν = 0.01/π`, `x ∈ [-1,1]`, `t ∈ [0,1]`, IC `u(x,0) = -sin(πx)` |
| Shared substrate | Sine spectral separation `K = 300` + Galerkin RK4 ODE for `β_k(t)` |
| Reference | ETDRK4 high-resolution solution (used only for evaluation — no data leakage) |
| Budget | 209,196 params (±10%) for neural methods |
| Training | head-reset LS init + Adam(10000) + L-BFGS(3000), float64 |
| Temporal backbones | SV-SNN (shared SIREN + heads), FourierPINN-style, PINN-style (tanh), per-mode SIREN, Chebyshev (classical) |
| Seeds | 3 for neural methods (+ 1 Chebyshev run) |

## Key results

Same-paradigm comparison — relative L2 (mean ± std):

| Temporal representation | Rel L2 | Params | Train time | Peak VRAM | Inference |
|-------------------------|-------:|-------:|-----------:|----------:|----------:|
| **SV-SNN** | **5.56e-6 ± 1.8e-8** | 209,196 | 73.9 s | 90.8 MB | 2.4 ms |
| FourierPINN-style | 5.47e-6 ± 5.4e-9 | 209,207 | 94.8 s | 92.3 MB | 2.6 ms |
| Chebyshev (classical) | 5.39e-6 | 76,800 | 11.2 s | 85.4 MB | 1.8 ms |
| PINN-style (tanh) | 2.17e-4 ± 3.0e-5 | 209,196 | 73.9 s | 90.8 MB | 2.7 ms |
| SIREN (per-mode) | 6.0e-4 ± 1.4e-5 | 201,900 | 733.7 s | 419.9 MB | 2.9 ms |

Pure-residual track (Appendix A, ~2k params, no Galerkin substrate):

| Method | SV-SNN | FourierPINN | SIREN | PINN | SPINN |
|--------|-------:|------------:|------:|-----:|------:|
| Rel L2 | 0.325 | 5.57e-3 | 6.90e-3 | 1.64e-2 | 3.11e-2 |

## Conclusions

- On the shared spectral-Galerkin substrate, SV-SNN reaches the spectral-method floor (L2 ≈ 5.56e-6), statistically tied with Fourier features and Chebyshev.
- The shared SIREN + linear heads design is ~40× better than tanh and ~100× better than per-mode SIREN, with ~10× faster training and ~4.6× less VRAM.
- In the pure-residual PINN paradigm, this non-separable shock defeats *all* methods including SV-SNN (0.325) — an honestly reported limitation. See `v10_critical_analysis.md` for the methodology note (the hybrid is a spectral-neural NICM, not a pure residual PINN).
