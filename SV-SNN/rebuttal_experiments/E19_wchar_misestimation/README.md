# E19 — `w_char` Misestimation Robustness

**Purpose.** Evaluate how SV-SNN degrades when the frequency prior `w_char = ρκ` is deliberately wrong, and test whether FFT-based auto-estimation removes the need for manual tuning.

**Reviewer comments addressed.** What if `w_char` requires prior knowledge and is misestimated?

## Setup

| Item | Detail |
|------|--------|
| PDE | Poisson on `[0,1]²`, `u = sin(κx)sin(κy)`, κ = 24π |
| `ρ` scan | 0.5, 0.7, 0.85, 1.0, 1.2, 1.5, 2.0 |
| Methods | SV-SNN, FourierPINN, SPINN, SIREN (+ PINN, SV-SNN-FFTauto) |
| FFT auto | `ŵ_char = 75.398 = 24.00π` (0% error vs true κ) |
| Seeds | 3 (90 runs for the ρ-scan + 6 independent) |

## Conclusions

- A frequency prior is essential — the prior-free PINN fails (~8).
- SV-SNN's sensitivity is asymmetric: severe **underestimation** (ρ = 0.5) is fatal (~0.99), while **overestimation** is safe and even optimal (ρ ∈ [1.2, 1.5]: 0.005–0.011).
- SPINN is the most robust to misestimation; FourierPINN/SIREN are the most fragile.
- SV-SNN-FFTauto recovers optimal accuracy without any manual prior (pairs with the auto-estimation in E5).
