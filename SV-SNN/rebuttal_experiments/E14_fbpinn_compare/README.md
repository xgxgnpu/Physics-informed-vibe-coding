# E14 — FBPINN / Domain-Decomposition Comparison

**Purpose.** Compare SV-SNN against the local-basis FBPINN (a domain-decomposition method) on the same perforated-domain benchmark used in E10, to position SV-SNN relative to the domain-decomposition paradigm.

**Reviewer comments addressed.** R5.5 (local-basis / FBPINN methods).

## Setup

| Item | Detail |
|------|--------|
| Domain | `[0,1]²` minus a circular hole (same as E10) |
| PDE | Poisson, `u = sin(μx)sin(μy)`, μ = 6π |
| Methods | SV-SNN (2328), FBPINN 4×4 matched (3280), FBPINN-rich 6×6 (12132), FourierPINN (57953) |
| Training | 8000 epochs, Adam (lr = 1e-3) |
| Seeds | 3 |

## Key results

| Method | Masked best L2, mean (min) | Params | Time |
|--------|---------------------------:|-------:|-----:|
| **SV-SNN** | **0.0372 (0.0254)**, std 0.011 | 2328 | 14.2 s |
| FBPINN 4×4 matched | 1.054 (0.956), std 0.086 | 3280 | 43.1 s |
| FBPINN-rich 6×6 | 0.614 (0.461), std 0.108 | 12132 | 120.6 s |
| FourierPINN | 0.215 (0.202), std 0.010 | 57953 | 14.5 s |

## Conclusions

- SV-SNN is ~5.8× better than FourierPINN, ~28× better than matched FBPINN, and ~16× better than FBPINN-rich.
- SV-SNN uses the fewest parameters and trains fastest (14 s vs 43–121 s for FBPINN variants).
- FBPINN needs more subdomains/tuning for this global high-frequency separable solution; the local-basis strength is better suited to multi-scale problems and local singularities. FBPINN represents the domain-decomposition paradigm (alongside XPINN/BsPINN) discussed separately in the manuscript.
