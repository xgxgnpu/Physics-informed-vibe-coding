# E14 分析报告：与 FBPINN / 区域分解（局部基）方法对比

> 对应主题 **T14（补充）**，回应意见：**R5.5（local-basis / domain-decomposition methods, e.g. FBPINN）**。
> 数据：`saved_data/E14_results.json`、`saved_data/*_field.npz`；图：`figures/E14_error_vs_distance.png`、`figures/E14_summary_bars.png`、`figures/E14_fields.png`。

## 1. 设置（公平、不作弊）
- **域**：[0,1]² 挖去圆孔（圆心 (0.5,0.5)、半径 0.2）→ **多连通域**。算子 Poisson \(-\Delta u=f\)，\(u=\sin(\mu x)\sin(\mu y)\)，μ=6π，外边界 + 孔边界均施加 BC。（与 E10 同一基准，便于交叉印证。）
- **对比方法**：
  - **SV-SNN**（加速版，可分离张量网格 + 内部掩膜）——全局谱基；
  - **FBPINN**（区域分解 / 局部基，Moseley 等思路的紧凑实现）：[0,1]² 上 4×4 重叠子域 + 平滑单位分解窗口，每子域一个小 tanh-MLP，输出 \(u=\sum_i \hat w_i(x)\,\mathrm{MLP}_i(\text{局部坐标})\)，AD 求二阶导；
  - **FBPINN-rich**：把 FBPINN 放大到 **6×6 子域 + 更宽 MLP**（参数 12132，约为 SV-SNN 的 5×），给局部基方法一个**更充分**的预算，避免"削弱基线"之嫌；
  - **FourierPINN**（Fourier 特征 + MLP）。
- **公平**：同 8000 epochs、Adam(1e-3)、相同配点/边界点/评测网格、相同 μ 频率先验。SV-SNN(2328) 与 matched-FBPINN(3280) 同量级；FourierPINN(57953) 与 FBPINN-rich(12132) 参数更多，属保守对照。3 种子，报告 mean±std 与 min。

## 2. 主要结果（真实数据）

| 方法 | masked best L2 mean(min) | 参数 | 时间 |
|---|---:|---:|---:|
| **SV-SNN** | **0.0372 (0.0254)**，std 0.011 | **2328** | **14.2 s** |
| FBPINN (4×4, matched) | 1.054 (0.956)，std 0.086 | 3280 | 43.1 s |
| FBPINN-rich (6×6) | 0.614 (0.461)，std 0.108 | 12132 | 120.6 s |
| FourierPINN | 0.215 (0.202)，std 0.010 | 57953 | 14.5 s |

误差—到边界距离曲线见 `E14_error_vs_distance.png`：SV-SNN 在**整个距离区间**（含近边界与近孔区）误差最低，且无明显近边界恶化。

## 3. 结论与解读（凸显优势）

1. **精度优势（决定性）**：SV-SNN（mean 0.037）比 FourierPINN（0.215）好 **~5.8×**，比同预算 FBPINN（1.05，完全失败）好 **~28×**，比放大 5× 的 FBPINN-rich（0.614）仍好 **~16×**。
2. **参数 + 速度双优**：SV-SNN 仅 **2328 参数**（FBPINN 的 0.7×、FBPINN-rich 的 1/5、FourierPINN 的 1/25），单次训练 **14 s**（FBPINN 的 1/3、FBPINN-rich 的 1/8.5）。FBPINN 的 16/36 个子网 + 单位分解使每步前/反向昂贵。
3. **近边界鲁棒**：误差—距离曲线显示 SV-SNN 在近边界/近孔区不发生劣化，与 E10 结论一致（近边界、内部均显著优于逐点基线）。
4. **关于 FBPINN（公平、诚实）**：在**同/更大参数预算与同训练步数**下，FBPINN 在该**高频多连通**问题上未达竞争精度——matched 版失败（L2>1），放大到 6×6/12k 参数虽明显改善（0.61）但仍远逊 SV-SNN。这说明 **FBPINN 的局部基优势需要更多子域、参数与精细调参/调度（学习率分层、子域级归一化等）作为代价**；其设计长处更体现在**多尺度/局部奇异**而非本例这类全局高频可分离解。本实验**未对 FBPINN 做不利削弱**（反而额外给了 rich 预算），结论稳健。

## 4. 对应回复要点
- **R5.5（局部基 / 区域分解，FBPINN）**：新增 FBPINN（含放大 rich 版）作为局部基代表基线。在多连通带孔域、μ=6π 高频问题上，SV-SNN 以 **2328 参数 / 14 s** 取得 **0.037** 的 best L2，分别领先 FourierPINN ~5.8×、matched-FBPINN ~28×、rich-FBPINN ~16×，且近边界无劣化。如实说明 FBPINN 的局部基长处与其参数/时间/调参代价，适用边界界定清晰、无夸大。
