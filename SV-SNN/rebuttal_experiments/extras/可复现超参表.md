# SV-SNN 可复现性与完整超参数说明（回应 R8.1、R9.6、R4.3、ED-2）

> 本表汇总 SV-SNN 的**完整架构定义**、**所有超参数**、**每个基准的特征频率 w_char 选择依据**、**频率可学习/冻结设置**、**随机种子、采样策略、损失权重、测试集构造**，以满足可复现性要求。

## 1. 架构完整定义（回应 R8.1）

SV-SNN 对 d 维问题（坐标 \(z_1,\dots,z_d\)，可含时间）的输出为：
\[
u(z_1,\dots,z_d)=\sum_{n=1}^{N} c_n \prod_{j=1}^{d} \Phi_n^{(j)}(z_j),\qquad
\Phi_n^{(j)}(z_j)=\sum_{k=1}^{K}\big(a^{(j)}_{n,k}\cos(\omega^{(j)}_{n,k} z_j)+b^{(j)}_{n,k}\sin(\omega^{(j)}_{n,k} z_j)\big)+\beta^{(j)}_n
\]

- **N**：分离模态数（mode count）。
- **K**：每个一维谱基的频率数（Fourier features per axis）。
- **可训练参数**：模态系数 \(c_n\)、每轴谱系数 \(a_{n,k},b_{n,k}\)、偏置 \(\beta_n\)。
- **频率 \(\omega_{n,k}\)**：默认**冻结**（frozen，`stop_gradient`），由多级采样初始化（见 §3）；可选**可学习**（见 E5 实验，wrong-prior 时可部分自校正）。
- **参数量**：\(\;\#\theta = N + d\cdot N\cdot(3K+1)\)，**随维度 d 线性增长**（对比稠密张量积基的 \(O(K^d)\)）。

## 2. 统一训练配置

| 项 | 取值 |
|----|------|
| 优化器 | Adam，学习率 \(1\times10^{-3}\) |
| 训练轮数 | 10,000（Case 9 稳态NS 为 15,000） |
| PDE 配点 | 10,000（Case 9 为 5,000）；加速版在可分离网格上为 \(N_c\times N_c\)（如 100×100） |
| 评估间隔 | 每 100 epoch |
| 精度框架 | JAX float32，GPU |
| 损失权重 | PDE 残差项与边界/初值项权重均为 **1.0**（等权；未做逐项加权调参） |
| L2 相对误差 | \(\sqrt{\sum(u_{pred}-u_{exact})^2/\sum u_{exact}^2}\) |
| 随机种子 | 主对比与敏感性实验用 **5 个种子（0–4）** 报告 mean±std；消融用 3 个种子 |
| 测试集 | 在求解域上的**均匀细网格**（如 256×256）评估，独立于训练配点 |

## 3. 多级频率采样与 w_char 选择依据（回应 R4.3、R9.6）

**多级采样（默认三级，25%/50%/25%）**：
- 低频段：\(\mathrm{linspace}(1,\,w_{char})\) 取 25% 频率；
- 特征段：\(\,|\,\mathcal N(0,1)\cdot \sigma + w_{char}\,|\) 取 50%（围绕特征频率）；
- 高频段：\(\mathrm{Uniform}(0.5\,w_{char},\,w_{char})\) 取 25%。
- 流问题（Taylor-Green / 双圆柱 NS）改用 **40%/40%/20%**，原因见 E4：流场低频能量占比更高，强调低/特征段更优。

**每个基准的 w_char（取主导频率）**：

| 基准 | 方程 | w_char | 选取依据 |
|------|------|--------|---------|
| Case 1 热方程 | κ=20π | 20π | 初值 sin(20πx) 的主频 |
| Case 2 Helmholtz | κ=24π | 24π | 解析解主频 κ |
| Case 3 非线性椭圆 | ω=10 | ~10 | cos(10x)sin(10y) 主频 |
| Case 4 热方程(极高频) | κ=500π | 500π | 初值主频 |
| Case 5 Helmholtz(圆柱) | κ=24π | 24π | 解析解主频 |
| Case 6 Helmholtz | κ=48π | 48π | 解析解主频 |
| Case 7 Poisson(多孔) | μ=7π | 7π | 解析解主频 |
| Case 8 Taylor-Green | Re=100 | 由初始涡量尺度定（~1–2 基波）| 流场主尺度 |
| Case 9 双圆柱 NS | — | 由几何/来流尺度定 | 低频主导 |

**当主导频率未知/多频/空间变化时**（回应 R1.5/R3.2/R5.1/R9.3）：见 E5，提供 (a) 敏感性 U 型曲线、(b) 多峰分配、(c) 空间变频、(d) **从源项/初值 FFT 自动估计 w_char**、(e) 冻结 vs 可学习、(f) 噪声先验 的完整证据。
