# E4 — Frequency Sampling Strategy Ablation

**Purpose.** Compare frequency-initialization strategies (single / two-level / three-level / continuous / 40-40-20) on a pure high-frequency and a multi-scale Poisson problem, plus a normalized-residual coverage test (E4b) that isolates spectral coverage from residual-magnitude imbalance.

**Reviewer comments addressed.** R7.2 (why three-level beats two-level/continuous) and R3.5 (why the 40/40/20 allocation for flow problems).

## Setup

| Item | Detail |
|------|--------|
| Model | Separable SV-SNN, M = 6 modes, K = 32 freqs/axis, 8000 epochs, Adam (lr = 1e-3) |
| Domain | 2D Poisson on `[0,1]²`, `u = 0` BC |
| Strategies | S1 single; S2 two (50% linear + 50% Gaussian); S3 three25 (25/50/25, paper default); S4 continuous; S5 three40 (40/40/20) |
| Problems | pure_high: `sin(24πx)·sin(24πy)`; multi_scale: `sin(4πx)sin(4πy) + sin(24πx)sin(24πy)` |
| Seeds | 3 |
| E4b | Normalized-residual coverage test; priors C1_low_only, C2_high_only, C3_multilevel |

## Key results

Pure high-frequency — best L2 (mean ± std):

| Strategy | Best L2 |
|----------|--------:|
| S1 single | 6.68e-4 ± 1.1e-4 |
| S2 two | 6.02e-2 ± 1.6e-2 |
| S3 three25 | 4.84e-2 ± 6.7e-3 |
| S4 continuous | 1.95e-2 ± 4.3e-3 |
| S5 three40 | 4.59e-2 ± 7.3e-4 |

Multi-scale under standard MSE — all strategies fail (residual-magnitude imbalance, not coverage):

| S1 | S2 | S3 | S4 | S5 |
|---:|---:|---:|---:|---:|
| 0.7071 | 0.7058 | 0.7072 | 0.7068 | 0.7069 |

E4b coverage test (normalized residual) — best L2 (mean ± std):

| Prior | Best L2 |
|-------|--------:|
| C1 low_only | 0.918 ± 5e-4 |
| C2 high_only | 0.707 ± 1e-5 |
| **C3 multilevel** | **0.0141 ± 3.5e-3** |

## Conclusions

- For an unknown single-frequency problem, broadband/three-level strategies are robust; the two-level strategy is the worst.
- The multi-scale failure under standard MSE is a **residual-magnitude imbalance** (≈36× between the low- and high-frequency source terms), not insufficient frequency coverage.
- With normalized residuals, multilevel coverage reduces error ~50–65× (0.014 vs 0.71–0.92), justifying the three-level and 40/40/20 allocations for multi-band spectra such as flow problems.
