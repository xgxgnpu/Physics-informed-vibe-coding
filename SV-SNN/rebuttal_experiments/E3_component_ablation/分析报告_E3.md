# E3 分析报告：逐模块消融（变量分离 / Fourier 谱基 / 多级采样 / 解析微分）

> 对应主题 **T3**，回应意见：**R7.5、R4.2、R10.1（"SV-SNN 是否仅是一种初始化策略"）**。
> 数据：`saved_data/E3_results.json`；图：`figures/E3_ablation.png`。

## 1. 设置
在**完全相同**的 SV-SNN 加速实现、训练超参（10000 epochs、Adam lr=1e-3、相同配点/网格、相同 w_char 频率先验）下，逐一关闭单个组件，量化其边际贡献。变体如下：

| 变体 | 变量分离 | Fourier 谱基 | 多级采样 | 解析微分 | 参数量 |
|---|:---:|:---:|:---:|:---:|---:|
| **V0_Full**（完整 SV-SNN） | ✓ | ✓ | ✓ | ✓ | 1170 |
| V1_NoSeparation（去分离，直接 d 维谱基） | ✗ | ✓ | ✓ | ✓ | 1161 |
| V2_NoSpectral（谱基→逐轴 tanh-MLP） | ✓ | ✗ | — | AD | 8082 |
| V3_NoMultilevel（多级→单级随机频率） | ✓ | ✓ | ✗ | ✓ | 1170 |
| V4_NoAnalytic（解析空间导数→纯 AD） | ✓ | ✓ | ✓ | ✗ | 1170 |

每个变体在**两个**问题上跑 **3 个随机种子**，报告 best L2 的 mean±std：
- **separable**：可分离 2D Helmholtz（解 \(u=\sin(\kappa x)\sin(\kappa y)\) 形式）；
- **nonseparable**：弱非可分离 2D 问题（解含交叉耦合项）。

## 3. 结论与解读

### 3.1 哪些组件是"决定精度"的（回应 R7.5、R4.2）
两个问题上结论一致，按对精度的贡献排序：

1. **Fourier 谱基（最关键）**：去掉谱基改用同规模逐轴 tanh-MLP（V2），即使参数量增大近 7×（8082 vs 1170），L2 仍劣化到 **0.82–0.85**（约 17–27 倍）。这直接证明**精度增益来自谱基对高频的表征能力，而非网络容量**——容量更大反而更差。这是对"普通 MLP 即可"质疑的有力反驳。
2. **变量分离（关键）**：去掉分离结构（V1）后 L2 劣化到 **0.46–0.70**（约 10–23 倍）。分离结构是高频条件下可训练性的支柱（与 E6 有效秩结论一致）。
3. **多级采样（有贡献，非决定性）**：单级随机频率（V3）在可分离问题上与完整版几乎持平（0.0298 vs 0.0306），在非可分离问题上略差（0.069 vs 0.048）。说明**多级采样是稳健性/收敛性的优化项**，在更复杂频谱结构上收益更明显，但非精度的"开关"。
4. **解析微分（精度等价，意义在效率）**：V4 改用纯 AD，精度与完整版**统计等价**（可分离 0.0309 vs 0.0306；非可分离 0.0310 vs 0.0477，甚至均值更低但在 std 内），但**时间增加 ~40–50%**（13.3/14.1s vs 9.2/9.3s）。这与 E2 结论完全一致：**解析微分的价值是计算效率而非精度**。

### 3.2 直接回应 R10.1："SV-SNN 是否仅是一种初始化策略？"
**不是。** 消融数据清楚区分了"初始化"与"架构"两类组件：
- 若 SV-SNN 仅是频率初始化技巧，则去掉多级采样（V3，等价于"换一种频率初始化"）应导致显著退化——但实验显示 V3 仅有轻微影响（可分离问题几乎无差）。
- 真正决定性的是**架构组件**：**Fourier 谱基**（V2，劣化 17–27×）与**变量分离**（V1，劣化 10–23×）。这两者是结构性设计，与初始化无关。
- 因此 SV-SNN 的核心是"**可分离 × 谱基**"的架构，多级采样是其上的初始化增强项。这一证据链精准回应了 R10.1。

### 3.3 参数效率
完整 SV-SNN 以 **1170 参数**取得 0.03–0.05 L2；而 tanh-MLP 变体用 **8082 参数**（6.9×）反而只能到 0.82。说明谱基的高效性来自**与解结构匹配的归纳偏置**，而非参数堆叠。

## 4. 对应回复要点
- **R7.5**：逐模块消融完成，量化各组件边际贡献（谱基 > 分离 ≫ 多级采样 ≈ 解析微分对精度的影响）。
- **R4.2**：精度增益来源已分解——主要来自谱基与变量分离两个**架构**组件，而非参数规模或初始化。
- **R10.1**：以数据证明 SV-SNN 非"仅初始化策略"——关闭初始化项（多级采样）影响轻微，关闭架构项（谱基/分离）灾难性退化。
