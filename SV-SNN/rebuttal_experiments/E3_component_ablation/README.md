# E3 — Component Ablation

**Purpose.** Turn off one SV-SNN component at a time — keeping all hyperparameters and the frequency prior fixed — to quantify the marginal contribution of each ingredient on separable and weakly non-separable problems. Directly answers the question "is SV-SNN just an initialization strategy?".

**Reviewer comments addressed.** R7.5, R4.2, R10.1.

## Setup

| Item | Detail |
|------|--------|
| V0 | Full SV-SNN |
| V1 | NoSeparation |
| V2 | NoSpectral (tanh-MLP + AD) |
| V3 | NoMultilevel (frequency sampling disabled) |
| V4 | NoAnalytic (pure AD instead of analytic differentiation) |
| Training | 10,000 epochs, Adam (lr = 1e-3), same collocation/grid and `w_char` |
| Problems | separable 2D Helmholtz; weakly non-separable (cross-coupled) variant |
| Seeds | 3 per variant × problem |

## Conclusions

- The **Fourier spectral basis** and **variable separation** are decisive: removing either degrades accuracy by 10–27×.
- **Multilevel sampling** is a modest robustness boost (clearer on the non-separable case: 0.048 vs 0.069).
- **Analytic differentiation** is accuracy-neutral but ~40–50% faster than pure AD, consistent with E2.
- SV-SNN is *not* "just initialization": disabling multilevel (V3) barely hurts, while disabling the architecture (V1/V2) is catastrophic.
