# SV-SNN 审稿回复 - 完整实验方案总览

> 本文件给出**逐条审稿意见 → 实验/写作**的完整映射，并明确每个实验（E1–E10）的目的、设计、公平性约束、产出与所回应的意见。所有实验以 **加速版 SV-SNN**（解析空间导数 + 可分离网格评估）为 SV-SNN 实现，确保精度与速度同时为最优（要求#4）。

---

## 一、统一实验规范（公平性约束）

为保证"公平公正、不作弊"（要求#5），全部实验遵循以下统一规范：

1. **训练预算统一**：除非该实验本身就是研究预算影响，否则全部方法 `Epochs=10000`、`Adam(lr=1e-3)`、warmup 2 步后计时。
2. **硬件统一**：NVIDIA RTX 4090（24GB），JAX 0.10.1（GPU），float32。
3. **配点统一**：同一算例下所有方法使用相同 PDE 配点数与边界点数；网格类方法（SPINN/加速SV-SNN）使用相同分辨率网格。
4. **频率信息公平**：基线（FourierPINN/SIREN/SPINN）获得与 SV-SNN **相同的特征频率 w_char** 用于其 Fourier/正弦初始化（回应 R3.1/R5.2/R7.3）。
5. **统计严谨**：关键对比与公平对比跑 **5 个随机种子**（seed=0..4），报告 **mean±std** 与 best（回应 R3.4/R9.5）。
6. **计时口径明确**：训练时间（不含评估）、每 epoch 毫秒、峰值显存、是否含 SVD 成本、推理时间分别报告（回应 R5.7/R9.5）。
7. **数据先行**：每个实验先运行 `run_*.py` 把全部数值结果写入 `saved_data/`（json/npz/csv），再由 `plot_*.py` 读取并绘制**英文**顶刊风格图（`figures/`），最后写中文 `分析报告_*.md`。
8. **自包含**：每个 `run_*.py` 不 import 任何兄弟/项目文件，所需 SV-SNN 与基线实现内联在脚本内。

## 二、实验套件设计（E1–E10）

### E1 — 公平且完整的基线对比（加速 SV-SNN）
- **回应**：R3.1, R5.2, R7.3, R5.7, R9.5, R3.4，并为 T11(R5.3/R9.1) 提供经典谱参考。
- **算例（代表性 5 个）**：heat κ=20π、Helmholtz κ=24π、**Helmholtz κ=48π**（直击 R3.4 不一致）、Poisson 复杂多孔域 μ=7π、双圆柱稳态 NS。
- **方法**：加速 SV-SNN、SPINN、SIREN、FourierPINN、PINN，外加**经典 Fourier 谱/最小二乘配点参考解**（非学习方法，作为精度上界参考，回应 R5.3）。
- **公平**：所有 Fourier 类基线用相同 w_char 初始化；同 epoch、同配点、同硬件。
- **指标**：参数量、每epoch时间(ms)、总训练墙钟(s)、峰值显存(MB)、配点数、推理时间、best/final ReL2E 的 **mean±std(5 seeds)**。
- **关键澄清**：用同一脚本同时输出"单次 best/单次 final/5次平均±std"三种口径，解释论文 Table 2(单次)/Table 10(SVD 诊断单次)/Table 11(10次平均) 差异的来源（R3.4）；汇总 30–45s 口径的真实分布（R9.5）。
- **产出**：`comparison_5seed.csv`、`compute_metrics.csv`、英文条形/误差棒图、`分析报告_E1.md`。

### E2 — 混合微分 vs 纯自动微分
- **回应**：R1.2, R7.1, R10.2, R9.4(微分部分)。
- **设计**：固定同一 SV-SNN 结构与初始化，仅切换 PDE 残差中空间导数的计算方式：
  - (A) 纯 AD（嵌套 `jax.grad`）；
  - (B) 混合（解析空间二阶导 + 时间 AD，即加速版）。
- **扫频**：κ ∈ {20π, 40π, 60π, 80π, 100π}，比较精度、训练时间、每 epoch 时间、梯度范数稳定性、**解析导数 vs AD 导数的数值误差**（与精确二阶导比较）。
- **产出**：误差累积随频率曲线、加速比曲线、`分析报告_E2.md`。

### E3 — 逐模块消融（哪个模块主导增益）
- **回应**：R7.5, R4.2(部分), R10.1(部分)。
- **变体**（在相同问题/预算下逐一开关）：
  1. Full SV-SNN（分离 + 谱基 + 多级采样 + 解析微分）；
  2. − 变量分离（全耦合 2D Fourier 基）；
  3. − 谱基（用普通 MLP 替换三角基，保留分离）；
  4. − 多级采样（随机均匀频率初始化）；
  5. − 解析微分（用 AD，=E2 的 A，交叉印证）。
- **指标**：ReL2E、参数量、时间；分析模块是否可加 / 主导。
- **算例**：Helmholtz κ=24π（可分离）+ 一个弱非可分离问题。
- **产出**：消融条形图、贡献分解、`分析报告_E3.md`。

### E4 — 频率采样策略
- **回应**：R7.2, R3.5。
- **策略**：单级(全 w_char)、两级(低+特征)、**三级 25/50/25**、连续(单一高斯/均匀宽带)、**40/40/20**。
- **算例**：heat κ=20π、Helmholtz κ=24π、Taylor-Green（验证 40/40/20 在流问题更优，回应 R3.5）。
- **产出**：各策略 ReL2E 对比、收敛曲线、`分析报告_E4.md`。

### E5 — 特征频率 w_char 敏感性与自动估计
- **回应**：R1.5, R3.2, R4.3, R5.1, R9.3。
- **子实验**：
  - (a) **w_char/κ 扫描** {0.5,0.75,0.9,1.0,1.1,1.25,1.5,2.0}（不准确先验，回应 R3.2/R5.1）；
  - (b) **多主频问题**（解含两个分离频率，如 sin(k1 x)+sin(k2 x)），测单一/多 w_char（回应 R5.1/R9.3）；
  - (c) **空间变频率/chirp**（频率沿坐标变化，回应 R3.2/R5.1）；
  - (d) **FFT 自动估计**：从初值/源项 FFT 自动定 w_char，与人工对比（回应 R1.5）；
  - (e) **冻结 vs 可学习**频率（回应 R9.6 可复现 + 鲁棒性）；
  - (f) **噪声频率先验**（w_char 加噪，回应 R9.3）。
- **产出**：U 型敏感性曲线、自动估计误差表、`分析报告_E5.md`。

### E6 — 有效秩验证（预测性）
- **回应**：R1.3, R3.3, R8.2。
- **设计**：对 SV-SNN 与 PINN 在多频率（κ=20π/40π/80π）训练过程中计算各损失分量 Jacobian 的有效秩轨迹；
  - 验证 **有效秩 ↔ 最终 ReL2E** 的相关性（量化 R3.3）；
  - 展示 **训练早期有效秩可预测最终精度**（回应 R8.2 的"预测/处方"诉求）；
  - 验证奇异值衰减成因（频率越高衰减越快）。
- **产出**：有效秩-误差相关散点、奇异谱衰减图、`分析报告_E6.md`。

### E7 — 模态数 N 缩放
- **回应**：R5.4(模态部分), R8.5(精度-模态部分)。
- **设计**：N ∈ {1,2,4,6,8,12,16}，记录 ReL2E / 参数量 / 训练时间；
  - 在**可分离**问题（Helmholtz κ=24π）与**非可分离**问题（来自 E8）上分别做，展示非可分离需要更多模态（回应 R5.4 局限）。
- **产出**：N–精度/参数/时间三联图、`分析报告_E7.md`。

### E8 — 挑战性问题（精选 3 个，含局限）
- **回应**：R1.4(非周期), R3.6, R5.4(局限), R5.6, R8.6, R9.2, R9.4(非光滑), R10.3(非周期/间断)。
- **精选 3 问题**：
  1. **强耦合非可分离高频**：解形如 `u=sin(κ·(x²+y²))` 或旋转坐标 `sin(κ(x cosθ+y sinθ))·...` 的真正非可分离结构；
  2. **非周期 / 边界层**：奇异摄动对流扩散 `−ε u'' + u' = f`（ε 小，出现薄边界层），非周期非 Fourier 友好；
  3. **非均匀介质 / 空间变波数 Helmholtz**：`κ(x)` 随空间变化。
- **方法**：加速 SV-SNN 与基线对比；**诚实报告** SV-SNN 在何处仍领先、何处退化（→ Limitations）。
- **产出**：解/误差图、对比表、`分析报告_E8.md`。

### E9 — 3D / 高维可扩展性
- **回应**：R1.4(3D), R8.3, R8.5(维度), R10.3(3D+)。
- **设计**：
  - 新建**真 3D 空间** Poisson/Helmholtz on [0,1]³（d=3），SV-SNN 与基线对比；
  - 复用 case11 Klein-Gordon(2+1D) 作为时空 3D；
  - **维度缩放表**：d=1,2,3 时 SV-SNN 参数量/精度/时间随 d 的缩放（O(dK) vs 全连接 O(K^d)），回应 R8.5。
- **产出**：3D 切片图、维度缩放曲线、`分析报告_E9.md`。

### E10 — 复杂几何近边界误差
- **回应**：R5.5。
- **设计**：在复杂域（Poisson 多孔 μ=7π 或圆柱 Helmholtz）上，
  - 画**近边界误差空间分布图**（孔洞/角点附近）；
  - 量化 **误差 vs 到边界距离** 曲线；
  - 与一个基线（FourierPINN）对比，说明 SV-SNN 近边界行为。
- **产出**：近边界误差热图、误差-距离曲线、`分析报告_E10.md`。
