# E22 — Characteristic-Frequency Multi-Level Initialization Ablation

**Purpose.** A large-scale ablation of SV-SNN's core innovation — three-level frequency initialization around `w_char` — across all 9 benchmark cases, crossing the level count with the `w_char` scale to measure robustness under misestimation.

**Reviewer comments addressed.** Supports the core-innovation claim (multi-level initialization around the characteristic frequency).

## Setup

| Item | Detail |
|------|--------|
| Cases | 9 benchmark cases (case1–case9) |
| Ablations | level count: 3-level (multi) / 2-level / 1-level; `w_char` scale: 0.6, 1.0, 1.5 |
| Engine | same accelerated SV-SNN as E11/E15/E16 (`run_one_abl.py`) |
| Runs | **243** (9 × 3 × 3 × 3); 135 reused from E16/E15, 108 newly run |

## Key results

Accurate `w_char` (scale 1.0) — mean relative L2 over 3 seeds:

| Case | 3-level (multi) | 2-level | 1-level |
|------|----------------:|--------:|--------:|
| case1 | 5.53e-4 | 3.99e-4 | **1.73e-4** |
| case2 | 9.16e-3 | 5.25e-2 | **6.12e-4** |
| case3 | **1.99e-3** | 3.04e-2 | 3.96e-1 |
| case4 | 3.18e-3 | 3.79e-3 | **2.51e-4** |
| case5 | **1.15e-2** | 2.50e-2 | 1.00 |
| case6 | 9.08e-3 | 8.74e-2 | **1.55e-3** |
| case7 | 3.02e-2 | 1.42e-2 | **1.61e-4** |
| case8 | 9.60e-3 | 9.86e-3 | 9.24e-3 |
| case9 | 3.40e-4 | 3.39e-4 | 3.49e-4 |

Robustness (geometric-mean degradation under wrong `w_char`): **3-level 20.1× < 2-level 23.5× < 1-level 90.0×**.

Catastrophic failures (L2 > 0.1, out of 27 cells = 9 cases × 3 scales): **3-level: 6 | 2-level: 10 | 1-level: 16**.

Geo-mean L2 under wrong `w_char`: ×0.6 → 7.4e-2 (3-level); ×1.5 → 2.5e-2 (3-level); 1-level collapses to ~0.25.

## Conclusions

- 3-level initialization is the robust default: the fewest catastrophic failures and the lowest degradation under misestimated `w_char` (especially overestimation).
- 1-level can be best on pure single-frequency cases when `w_char` is exact, but fails catastrophically when `w_char` is wrong or on multi-frequency cases.
- Underestimation (×0.6) remains hard for all levels, which is why E22 pairs with the FFT auto-estimation in E19 (`ρ̂ = 1.00`).
