# E10 — Complex-Geometry Near-Boundary Error

**Purpose.** Characterize how SV-SNN's error behaves near holes and corners of a multiply connected domain, and compare it to a FourierPINN baseline as a function of distance to the nearest boundary.

**Reviewer comments addressed.** R5.5 (near-boundary error maps and baseline comparison).

## Setup

| Item | Detail |
|------|--------|
| Domain | Unit square `[0,1]²` with a circular hole (center (0.5, 0.5), r = 0.2) |
| PDE | Poisson `-Δu = f`, `u = sin(μx)sin(μy)`, μ = 6π, Dirichlet on outer + hole boundaries |
| Methods | SV-SNN (separable grid + interior mask) vs FourierPINN |
| Seeds | 3 |

## Key results

Overall masked best L2 (mean ± std):

| Method | Masked best L2 | Params |
|--------|---------------:|-------:|
| **SV-SNN** | **0.0487 ± 0.0106** | 2328 |
| FourierPINN | 0.2150 ± 0.0095 | 57953 |

Absolute error vs distance to nearest boundary (mean):

| Distance | ~0.005 (near) | ~0.026 | ~0.058 | ~0.10 | ~0.20 (interior) |
|----------|--------------:|-------:|-------:|------:|-----------------:|
| **SV-SNN** | 0.045 | 0.034 | 0.014 | 0.0064 | 0.0007 |
| FourierPINN | 0.171 | 0.121 | 0.074 | 0.045 | 0.042 |

## Conclusions

- SV-SNN's L2 is 4.4× better than FourierPINN's with 25× fewer parameters.
- Both methods show their largest error near boundaries; SV-SNN's near-boundary error is ~3.8× lower and its interior error ~60× lower.
- The masked separable grid is a practical approximation; a thin high-error layer remains at the curved hole boundary (motivating the FBPINN comparison in E14).
