## 第二部分 逐条一对一回复

### Reviewer #1

**R1.1（与 SPINN 的区别 / 原创性，需在 Introduction 与 §2 强调）**
SPINN（Cho et al. 2023）是**逐轴 MLP 的张量积分解**，本质仍是 tanh-MLP 表示，未对高频做谱设计；SV-SNN 的核心是 **可分离结构 × 自适应 Fourier 谱基 × 围绕特征频率的多级（三层）频率初始化 × 解析空间微分** 的整合。其中**"特征频率多级初始化"是与 SPINN 的关键区分点之一**，并已在 E22 上做了系统消融验证（见下）。
- 核心创新点的专项证据（E22，9 算例 × 级数{3/2/1} × w_char尺度{0.6/1.0/1.5} × 3 种子）：与"1级（全部频率钉在单一 w_char）/2级"相比，**多级（三层）初始化是鲁棒的核心默认**——对错误 w_char 的退化倍数 **多级 20× < 2级 24× < 1级 90×**，27 格灾难性失败 **多级 6 < 2级 10 < 1级 16**；机理是低频带 `[1,w_char]` 提供"安全网"，使 w_char 被高估时几乎不退化。该消融的"多级 + 准确 w_char"基准与 E11 SV-SNN 最佳逐位一致。详见 `E22_freq_init_innovation/分析报告_E22.md`。
- 数据支撑（E3 逐模块消融）：把谱基换成同规模逐轴 tanh-MLP（即"分离但非谱"），即便参数增大近 7×（8082 vs 1170），L2 仍劣化到 0.82–0.85（17–27×）；去掉变量分离 L2 劣化到 0.46–0.70（10–23×）。**高频精度来自谱基与分离结构，而非网络容量。**
- 同参数量对比（E11）：在 C2（Helmholtz 24π）SPINN-matched（1164 参）best L2 = 0.104，SV-SNN（1170 参）= 0.0092，领先 ~11×；在 C8（Taylor-Green）SPINN-matched 0.224 vs SV-SNN 0.0096，领先 ~23×。
- 已在 Introduction 与 §2 增补与 SPINN 的逐点对比表，并补充数学原理对比文档（`rebuttal_experiments/数学原理对比_SVSNN_vs_SPINN_FourierPINN.md`）。

**R1.2（混合微分：公式 + 稳定性 + 消融）**
- 解析二阶导数闭式公式（E2 §2）：一维谱基 \(\Phi(z)=\sum_k a_k\cos(\omega_k z)+b_k\sin(\omega_k z)+\beta\)，\(\Phi''(z)=\sum_k -\omega_k^2(a_k\cos+b_k\sin)\)；二维 \(\Delta u=\sum_n c_n(X_n''Y_n+X_nY_n'')\)，空间全解析、时间用 AD。
- 稳定性与消融（E2）：κ∈{20π…100π} 下混合 vs 纯 AD 全频段对比，混合稳定取得 **~2.5× 训练加速**，每 epoch 时间几乎不随频率增长。
- 见 R1.2/R10.2 的诚实修正：在光滑谱基上 AD 与解析二阶导数数值上等价（误差均为机器精度 ~1e-16），混合策略的核心收益是**效率与网格可扩展性**，而非精度。

**R1.3（有效秩 ↔ 谱偏的严谨性）**
见 E6：多频率（20π/40π/80π）下 **PINN 残差雅可比有效秩在 epoch≈500 即坍缩到 ≈3**，最终 L2≈1.0（失败）；**SV-SNN 维持有效秩 ≈150–250**，收敛到 L2 0.026–0.079。初始奇异谱对比表明 PINN 雅可比在高频下病态（奇异值快速衰减），SV-SNN 谱基使各频率方向解耦（奇异值平坦）。已在 §3.2 增补该因果链与定量证据。

**R1.4（泛化与局限：非周期 / 3D / 噪声 / 增设 Limitations 节）**
- 非周期局部波包：E8-Q2（高斯包络 sin），SV-SNN 0.013 vs 基线 0.19–0.30。
- 3D/高维：E9（真 3D Poisson，SV-SNN 0.008 vs FourierPINN 0.23 vs PINN 失败；参数随维度线性）。
- **噪声边界/初值条件（已补 E12）**：在 Helmholtz κ=24π 上对边界测量注入 0/1%/5%/10% 相对高斯噪声（物理残差保持干净，三方法吃完全相同含噪数据），SV-SNN best L2 在 0→10% 噪声下**无退化**（0.042→0.033，变化在种子方差内），始终比最强基线 FourierPINN（~0.33）好 **~8×**、比 PINN（~1.0）好 **~24×**，且参数仅为基线的 **1/42**。其冻结多级谱基 + 低秩可分离结构等效于对边界噪声的隐式正则。
- **空间变频 / chirp（已补 E18）**：见 R5.6——chirp 解（局部波数随空间增长）下，单频/中等变频 SV-SNN 最优或与 SPINN 并列，强变频(r=8)时 SPINN 反超（诚实局限）；据此扩充 Limitations。
- 已新增 **Limitations 专节**（综合 E2/E7/E8/E10/E13/E17/E18）：非可分离需 N≥分离秩、极高频需网格≥3 点/波长、曲边界需掩膜/区域分解、**尖锐边界层(ε≤0.01)对全局谱基最具挑战（E13）**、**极宽多频谱 + 极小预算时频带相互争用（E17）**、**强空间变频(chirp r≥8)下冻结谱不如可学习分支（E18）**。

**R1.5（无先验时如何估计 w_char）**
见 E5(d) + **E15a**：对源项/已知数据做 2D FFT 取主峰自动估计 w_char，与人工设定**完全一致（相对误差 0%，精度无损）**；多峰情形给出"取最高显著频率"准则（E5(b)，三级采样的低频段自动兼顾较低频率）。E15a 进一步在 9/9 算例上确认：自动/人工设定对应的 **×1.0 尺度即为最优或紧邻最优**，验证该估计准则的可靠性。

**R1.6（PIKAN 文献）**
已引用并讨论：10.1016/j.engappai.2026.114468、10.1007/s10518-026-02408-w（PIKAN 系列），在相关工作中对比 KAN 基与本文 Fourier 谱基的取舍（详见写作交付 `extras/写作交付_文献_标题_关键词_摘要.md`）。

### Reviewer #3

**R3.1（基线频率超参公平性，尤其 Fourier 类是否为高频调好）**

## 第三部分 补充实验（已补 E12–E14 + 真实数据；剩余诚实清单）

针对原先尚未直接覆盖的三条意见，我们已**补做三组独立、自包含、公平**的实验（E12/E13/E14，各含 `run/plot/分析报告` 与保存的数据/图），数据先行、3 种子、与 SV-SNN 同量级或更大的基线预算，**结果如实报告（含不足）**：

1. **噪声边界/初值条件鲁棒性（已补 E12，回应 R1.4 "robustness to noisy BC/IC"）** —— 目录 `E12_noisy_bc_ic/`。
   - 设置：Helmholtz κ=24π 可分离解，对边界测量注入 ε∈{0,1%,5%,10%} 相对高斯噪声（按解内部 RMS 标定，物理残差干净），SV-SNN / FourierPINN / PINN 吃**完全相同**含噪数据，统一 8000 epochs/同频率先验；对**干净解析解**评测。
   - 真实结果：SV-SNN best L2 = **0.042 / 0.042 / 0.038 / 0.033**（ε=0/1/5/10%），**无退化**（在种子方差 std≈0.009 内）；FourierPINN ~0.33（49.7k 参）、PINN ~1.0（失败，50k 参）全程几乎不变但绝对精度差 1–2 个数量级。SV-SNN 以 **1170 参（基线 1/42）** 领先 ~8×/~24×。
   - 结论：冻结多级谱基 + 低秩可分离结构对边界噪声构成隐式正则，鲁棒性不低于（甚至优于）大容量基线。

2. **边界层 / 奇异摄动（已补 E13，回应 R5.6 "boundary-layer problems"；诚实定位）** —— 目录 `E13_boundary_layer/`。
   - 设置：制造解 \(u=g(x)\sin(\pi y)\)，\(g\) 在 x=1 附近形成宽度 ~ε 的尖锐层（非周期、宽频），Poisson \(-\Delta u=f\)，ε∈{0.05,0.02,0.01}；w_char 给到 ~1.2/ε 的信息化先验；SV-SNN / FourierPINN / PINN 三方法。
   - 真实结果（mean(min)）：ε=0.05 → SV 0.521(0.266) / FP 0.242 / PINN **0.150**；ε=0.02 → SV **0.692(0.027)** / FP 1.28 / PINN 1.22；ε=0.01 → 三法皆败（FP 0.90、SV 2.07、PINN 5.9）。
   - 诚实结论：**尖锐边界层是全局谱方法的公认难点**——薄层(ε=0.01)三法全败。但 ε=0.02 时 SV-SNN 最优种子 0.027 远超完全失败的基线，说明谱基"能表达、欠稳定"，短板是刚性源致优化高方差。已写入 **Limitations** 与三条处方（坐标拉伸 / 局部·混合基 / 残差归一化）。SV-SNN 始终以 2322 参（基线 1/22–1/28）参与且单次最快(~10 s)。

3. **与局部基 / 区域分解方法对比（已补 E14，回应 R5.5 "local-basis / domain-decomposition methods"）** —— 目录 `E14_fbpinn_compare/`。
   - 设置：复用 E10 带孔多连通域（Poisson μ=6π），加入 **FBPINN**（4×4 重叠子域 + 平滑单位分解窗口 + 子域小 tanh-MLP，AD 求导）作为局部基代表，并额外提供 **rich 版（6×6 子域、12132 参）**避免削弱基线；与 FourierPINN 一并对比。
   - 真实结果（masked best L2 mean）：SV-SNN **0.037（2328 参 / 14 s）** ≪ FourierPINN 0.215（58k / 14.5 s） < FBPINN-rich 0.614（12.1k / 121 s） < matched-FBPINN 1.054（3.3k / 43 s，失败）。误差—距离曲线显示 SV-SNN 全程最低、近边界无劣化。
   - 结论：在同/更大预算与同训练步数下，SV-SNN 在该高频多连通问题上以最少参数与最短时间显著领先；FBPINN 的局部基长处需更多子域/参数/调参作为代价（如实报告，非削弱基线）。

   - 设置：参数族多频 Poisson 算子学习任务（64×64 网格，随机多频制造解），FNO 学 \(f\mapsto u\)（4 谱卷积块、modes16/width32、~4.2M 参，3 种子），训练集扫描 \(N_{train}\in\{64,256,1024\}\)、固定留出 100 实例；SV-SNN 对其中 16 个留出实例零数据物理信息求解（1170 参、5000 epochs）。

   - 诚实结论：两范式互补——**无数据/数据稀缺/少查询/极致参数效率** SV-SNN 占优（1170 参 vs 4.2M，0 解数据）；**富数据 + 海量同族查询** FNO 摊销后更快更准。既未回避 FNO 富数据优势，也客观展示 SV-SNN 不可替代性。

5. **完全不可分 Burgers 激波（已补 E21，回应 R3.6 / R5.4 / R8.6 / R9.2 的"真正非可分离"质疑）** —— 目录 `E21_burgers_nonseparable/`（全 JAX-GPU；ETDRK4 参考解 `saved_data/burgers_reference_hires.npz` 与算例放在一起）。
   - 设置：`u_t+u·u_x=ν·u_xx`，ν=0.01/π，x∈[-1,1]，t∈[0,1]，u(x,0)=-sin(πx)，u(±1,t)=0；t≈0.5 后形成激波，时空完全不可分。
   - **首要诚信声明（适用于本算例所有方法）**：本算例所有被比较方法（含 SV-SNN）共享**同一基底**——空间正弦谱分离 `u=Σβ_k(t)sin(kπx)`（K=300）+ **经典 Galerkin 投影 ODE（RK4, float64）** 求模态系数 β_k(t)（只算一次并缓存）。**PDE 由经典 Galerkin 求解器推进，神经网络只压缩 β_k(t)**；故此处 SV-SNN 是**谱-神经混合方法、非纯残差 PINN**（自我批判见 `v10_critical_analysis.md`）。该声明对所有方法等同成立，因此对比是**单变量、公平**的。
   - **同范式公平对比（唯一变量＝压缩 β_k(t) 的"时间表示"；等参数量 209k±10%、同训练计划、×3 种子、同 ETDRK4 参考）**，真实结果（相对 L2, mean±std）：**SV-SNN（共享 SIREN 主干 + 每模态线性读出头, =v10）= 5.56e-6 ± 1.8e-8**（74 s / 90.8 MB / 推理 2.4 ms）；FourierPINN-style(Fourier 特征)=5.47e-6（统计同级）；**经典 Chebyshev(无 NN, 参照)=5.39e-6**——三者共处谱方法精度地板。tanh-PINN-style=2.17e-4（差约 40×）；朴素 per-mode 独立 SIREN(v9 风格)=6.0e-4（差约 100×，且训练慢约 10× 达 734 s、显存高约 4.6× 达 420 MB）。
   - **结论**：在完全不可分激波上，**SV-SNN 以约 21 万参数、74 秒达到 L2≈5.6e-6 的经典谱方法级精度**（误差仅集中于激波尖点），且其"共享主干+廉价线性头"设计在精度、速度、显存上全面优于朴素 per-mode 神经表示、显著优于 tanh 表示。我们**不夸大**：SV-SNN 与 Fourier 特征统计打平，二者皆触达经典地板。
   - **附录（诚实记录纯残差范式的局限）**：若**不**用 Galerkin 基底而以**纯残差 PINN**直接拟合该激波，则**所有方法都很差**（纯残差 SV-SNN 0.325、FourierPINN 5.6e-3、SIREN 6.9e-3、PINN 1.6e-2、SPINN 3.1e-2；SV-SNN 因可分谱-线性空间 ansatz 无法变陡，秩 8→64、先验 ×0.2→×6.7 扫描均无改善——结构性局限）。**这正是本算例采用谱-神经混合范式的动机**，已如实写入 Limitations。

## 第六部分 诚实声明

本回复中所有数值均来自本轮重新运行的实验（加速版 SV-SNN，统一硬件/预算/种子），保存于 `E11_grand_fair_comparison/saved_data/` 与各 `Ex/saved_data/`、图件 `*/figures/`。我们**如实报告了若干"非全胜"的发现**与代价：E2 的高频网格混叠（κ≥80π 需 ≥3 点/波长）、对"避免 AD 误差累积"表述的诚实修正、E4 的多尺度残差幅度失衡（独立于采样的损失加权问题）、E5 可学习频率不优于冻结、E8 非可分离需更多模态且方差增大、E10 曲边界薄层误差较高、**E13 尖锐边界层(ε≤0.01)对全局谱基最具挑战且种子方差大**。补充实验 E12/E13/E14 已直接闭合"噪声 BC/IC、边界层、局部基/区域分解对比"三条意见（含 E13 的诚实局限定位）；E15/E16 进一步对 SV-SNN **自身结构**做了逐算例公平消融，并**如实指出**：(i) 三层频率分层并非在每个理想化基准上误差最低，而是"全场不翻车"的稳健默认——在纯单频解析解(C2/C4/C6/C7)上单频初始化反而更准，但其在非线性 C3、绕障碍 C5 上会崩溃到 100% 误差；(ii) E15 的结构分解使用 E11 匹配参数基线作为"去分离/去谱基"的受控代理（逐字节硬开关消融已在 E3 给出）；(iii) C7 的 w_char 谷底偏平、C8/C9 对频率尺度不敏感。E17/E18/E19 进一步在多频/变频/错误先验三类频率场景上做了 SV-SNN vs 全基线的等参数量公平对比，并**如实报告了非全胜的发现**：(i) E17 极宽多频谱(4 分量) + 极小预算时所有方法都吃力，SV-SNN 虽整体最优但逐分量显示其低频带欠拟合；(ii) **E18 强变频(chirp r=8)下 SPINN 反超 SV-SNN**（冻结谱不如可学习分支）；(iii) E19 中 SV-SNN 对严重低估的 w_char 敏感（冻结频率够不到真频），SPINN 对先验失准最鲁棒——但 SV-SNN-FFTauto 通过源项 FFT 自动估计（0 误差）即可消除人工先验需求并恢复最优精度。E20 补做了 FNO（数据驱动）vs SV-SNN（物理信息）的同框架对照，并**如实承认 FNO 在富数据下（≥256–1024 解）精度更高**，仅强调 SV-SNN 在零数据 / 参数效率（1170 vs 4.2M）/ 少量查询上的不可替代性。E21 补做了**完全不可分 Burgers 激波**的对照，并**毫不回避地承认最不利的发现**：作为**纯残差 PINN**，SV-SNN 在该激波上**失败**（0.325，劣于全部基线），且容量/先验扫描证明这是其可分谱归纳偏置的**结构性局限**而非欠调——我们如实写入 Limitations；高精度（5.8e-6）仅由保留谱分离的**混合方案**（经典 Galerkin ODE + 神经压缩）取得，并**显式声明该方案不是 PINN**（PDE 由经典谱方法求解、网络只做压缩、参考解仅用于评估、无数据泄露），随附 `E21.../v10_critical_analysis.md` 自我批判。仅余代码库可访问性核验列于第三部分⑥，**绝不以编造数据搪塞**。
