# E9 — High-Dimensional / 3D Scalability

**Purpose.** Demonstrate genuine 3D capability and the linear parameter/time scaling of SV-SNN with spatial dimension, addressing the lack of d ≥ 3 experiments and the question of how N scales with dimension.

**Reviewer comments addressed.** R8.3 (no d ≥ 3 results), R8.5 (N scaling with dimension/accuracy), R1.4, R10.3.

## Setup

| Item | Detail |
|------|--------|
| Part A | 3D Poisson on `[0,1]³`, `u = sin(kx)sin(ky)sin(kz)`, `-Δu = 3k²u`, k = 8π, `u = 0` on boundary |
| Part B | Same per-axis frequency content for d = 1, 2, 3 (SV-SNN only) |
| Model | accelerated SV-SNN (3D separable), M = 6, K = 24, 6000 epochs, lr = 1e-3 |
| Baselines (Part A) | vanilla PINN, FourierPINN |
| Seeds | 3 |

## Key results

Part A — 3D Poisson, best relative L2 (mean):

| Method | Best L2 | Params | Time (s) |
|--------|--------:|-------:|---------:|
| **SV-SNN (3D separable)** | **0.0083** | 1320 | 8.0 |
| FourierPINN | 0.228 | 51785 | 9.4 |
| PINN | 4.81 (range 2.5–8.4) | 50177 | 9.9 |

Part B — dimension scaling (SV-SNN, mean ± std):

| d | Params | Best L2 | Time (s) |
|--:|-------:|--------:|---------:|
| 1 | 444 | 0.0022 ± 0.0012 | 2.8 |
| 2 | 882 | 0.0154 ± 0.0044 | 6.2 |
| 3 | 1320 | 0.0083 ± 0.0014 | 8.0 |

## Conclusions

- SV-SNN reaches L2 ≈ 0.008 in true 3D with only 1320 params (~27× better than FourierPINN; PINN fails at L2 > 1).
- Parameters grow linearly, O(d·M·K): 444 → 882 → 1320 (+438 per dimension), with stable accuracy and near-linear time.
- The benchmark uses a separable rank-1 3D solution (same caveat as E7/E8).
