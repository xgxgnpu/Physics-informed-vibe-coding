# E2 — Hybrid Analytic Differentiation vs Pure Auto-Diff

**Purpose.** Ablate *only* the spatial-derivative computation inside the same SV-SNN: closed-form spectral differentiation on a separable grid versus nested `jax.grad`+`vmap` automatic differentiation on scattered points. We measure training speed, derivative accuracy, and relative L2 across a sweep of wavenumbers.

**Reviewer comments addressed.** R1.2, R7.1, R10.2, R9.4 (the differentiation-strategy aspect).

## Setup

| Item | Detail |
|------|--------|
| PDE | 2D Helmholtz |
| Wavenumbers | κ = 20π, 40π, 60π, 80π, 100π |
| Variant A | Pure AD on 10,000 scattered points |
| Variant B | Hybrid / analytic differentiation on a separable grid |
| Grid study | κ = 100π, `N_c ∈ {100, 150, 200, 300, 400}` |
| Seeds | 3 per (κ, variant) |

## Key results

Training speed:

| κ | Hybrid (s) | Pure AD (s) | Speedup | ms/epoch (hybrid / AD) |
|---|-----------:|------------:|--------:|-----------------------:|
| 20π | 11.0 | 26.5 | 2.40× | 1.84 / 4.42 |
| 40π | 10.3 | 26.4 | 2.58× | 1.71 / 4.40 |
| 60π | 10.4 | 26.4 | 2.54× | 1.74 / 4.41 |
| 80π | 10.5 | 26.7 | 2.53× | 1.76 / 4.45 |
| 100π | 10.5 | 26.7 | 2.55× | 1.75 / 4.46 |

Derivative accuracy vs float64 analytic `u_xx` (relative error): analytic float32 = 0.0; pure-AD float32 = 2.6e-16 – 3.0e-16 across all κ (both at machine precision).

Best L2 (mean ± std):

| κ | Hybrid | Pure AD |
|---|--------|---------|
| 20π | 0.0318 ± 0.0141 | 0.0422 ± 0.0269 |
| 40π | 0.0160 ± 0.0011 | 0.0151 ± 0.0013 |
| 60π | 0.0087 ± 0.0016 | 0.0167 ± 0.0046 |
| 80π | 0.0707 ± 0.0057 | 0.0214 ± 0.0034 |
| 100π | 0.790 ± 0.120 | 0.0220 ± 0.0121 |

Grid-resolution study at κ = 100π (hybrid):

| Grid `N_c` | pts/wavelength | Best L2 | Time (s) |
|-----------:|---------------:|--------:|---------:|
| 100 | 2.0 | 0.790 | 10.4 |
| 150 | 3.0 | **0.0175** | 10.3 |
| 200 | 4.0 | 0.0208 | 10.7 |
| 300 | 6.0 | 0.0213 | 10.4 |
| 400 | 8.0 | 0.0204 | 10.2 |

## Conclusions

- Hybrid analytic differentiation gives a stable ~2.5× training speedup, and its per-epoch cost barely grows with frequency.
- On smooth spectral bases, AD second derivatives are already at machine precision, so the benefit is **efficiency and grid scalability**, not derivative accuracy.
- The hybrid failure at κ = 100π on a 100×100 grid is **Nyquist aliasing**, not a method defect: using ≥3 points per wavelength (`N_c ≥ 150`) restores ~0.02 L2 at unchanged wall-clock time.
