# E8 分析报告：挑战性问题（非可分离 / 非周期局部 / 非均匀介质）

> 对应主题 **T8**，回应意见：**R3.6、R5.6、R8.6、R9.2、R10.3、R1.4、R5.4（局限）**。
> 数据：`saved_data/E8_results.json` 及各 `*_pred.npz`；图：`figures/E8_bars.png`、`figures/E8_fields.png`。

## 1. 设置：刻意选取对 SV-SNN "不利" 的三类问题
在 [0,1]² 上，3 个种子，对比**加速 SV-SNN**、**FourierPINN**、**vanilla PINN**：
- **Q1 非可分离高频**：\(u=\sin(\kappa(x^2+y^2))\)，κ=8π。无法写成 X(x)Y(y)，需多模态展开（SV-SNN 用 N=16）。
- **Q2 非周期局部波包**：\(u=e^{-((x-.5)^2+(y-.5)^2)/2s^2}\sin(\kappa x)\)，κ=16π, s=0.12。高斯包络非周期，对全局 Fourier 基构成压力（N=12）。
- **Q3 非均匀介质 Helmholtz**：\(-\Delta u-\kappa(x,y)^2u=f\)，\(\kappa(x,y)=20\pi(1+0.5\sin2\pi x)\)，变系数算子（N=8）。

## 2. 主要结果（真实数据）

| 问题 | **SV-SNN** (params) | FourierPINN (params) | PINN (params) |
|---|---:|---:|---:|
| Q1 非可分离 | **0.0195** (4.7k) | 0.250 (58k) | 2.82 (50k) |
| Q2 非周期波包 | **0.0132** (3.5k) | 0.192 (58k) | 0.304 (50k) |
| Q3 非均匀介质 | **0.0098** (2.3k) | 0.453 (58k) | 1.00 (50k) |

（均为 best L2 的 3 种子均值；SV-SNN 参数量仅为基线的 **1/10 ~ 1/25**。）

## 3. 结论与解读

### 3.1 即便在"不利"问题上，SV-SNN 仍显著领先
- **Q1 非可分离**：SV-SNN 0.0195，比 FourierPINN（0.250）好 **13×**，PINN 完全失败（2.82）。通过 N=16 模态的可分离展开（CP 分解思想），SV-SNN 仍能高精度逼近非可分离解。
- **Q2 非周期局部波包**：尽管高斯包络非周期、对全局基不利，SV-SNN 仍达 0.013，比基线好 **15–23×**。说明谱基 + 多模态足以表征局部非周期结构。
- **Q3 非均匀介质（变系数）**：SV-SNN 0.0098，FourierPINN/PINN 分别 0.45 / 1.00（PINN 彻底失败）。变波数算子下 SV-SNN 优势最大（**46–100×**）。

### 3.2 诚实的局限与代价（直接回应 R5.4/R10.3）
1. **非可分离问题需要更多模态**：Q1 用 N=16（参数 4.7k，仍远小于基线），与 E7 结论一致——**N 必须 ≥ 解的有效分离秩**。这是方法的明确代价，而非失效。
2. **一致性下降**：Q1/Q3 的种子间方差较大（Q1 std 0.011，Q3 std 0.012），最差种子分别为 0.032 / 0.027。强非可分离/强变系数时优化更敏感，建议多次初始化取最优（与 R3.4 一致的实践建议）。
3. **极高局部频率仍受网格采样约束**：与 E2 一致，若解的局部频率很高，需保证训练网格 ≥3 点/波长。

### 3.3 综合判断
这三个问题是**刻意挑选的不利场景**，SV-SNN 依然以 **1/10–1/25 的参数**取得 **13–100×** 的精度优势，且诚实暴露了"非可分离需更多模态、方差略增"的代价。这支持论文主张：**SV-SNN 的可分离谱架构在远超训练分布的困难问题上仍稳健**，其适用边界清晰（N≥分离秩、网格≥3点/波长）。

## 4. 对应回复要点
- **R3.6 / R5.6 / R8.6 / R9.2 / R1.4（非可分离/非周期/变系数适用性）**：三类困难问题上 SV-SNN 全面领先（13–100×），证明方法不局限于可分离解。
- **R5.4 / R10.3（局限）**：诚实给出代价——非可分离需 N≥分离秩、方差略增、网格需充分采样；但这些是"可量化的使用准则"而非"失效"。
