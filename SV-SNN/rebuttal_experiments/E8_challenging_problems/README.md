# E8 — Challenging Problems (Non-Separable / Aperiodic / Heterogeneous)

**Purpose.** Stress-test SV-SNN on deliberately unfavorable problems — a non-separable high-frequency solution, an aperiodic localized wave packet, and a variable-coefficient (heterogeneous-medium) Helmholtz problem — against FourierPINN and vanilla PINN.

**Reviewer comments addressed.** R3.6, R5.6, R8.6, R9.2, R10.3, R1.4, and R5.4 (honest limitations).

## Setup

| Item | Detail |
|------|--------|
| Domain | `[0,1]²` |
| Q1 Non-separable | `u = sin(κ(x²+y²))`, κ = 8π, SV-SNN N = 16 |
| Q2 Aperiodic packet | `u = exp(-((x-.5)²+(y-.5)²)/(2s²))·sin(κx)`, κ = 16π, s = 0.12, N = 12 |
| Q3 Heterogeneous Helmholtz | `-Δu - κ(x,y)²u = f`, `κ(x,y) = 20π(1+0.5·sin 2πx)`, N = 8 |
| Methods | SV-SNN, FourierPINN, vanilla PINN |
| Seeds | 3 (best L2, mean ± std) |

## Key results

Best relative L2 (params in parentheses):

| Problem | **SV-SNN** | FourierPINN | PINN |
|---------|-----------:|------------:|-----:|
| Q1 Non-separable | **0.0195** (4.7k) | 0.250 (58k) | 2.82 (50k) |
| Q2 Aperiodic packet | **0.0132** (3.5k) | 0.192 (58k) | 0.304 (50k) |
| Q3 Heterogeneous | **0.0098** (2.3k) | 0.453 (58k) | 1.00 (50k) |

Speedups vs the best baseline: Q1 ~13×, Q2 ~15–23×, Q3 ~46–100×.
Seed variance (from report): Q1 std 0.011 (worst seed 0.032); Q3 std 0.012 (worst seed 0.027).

## Conclusions

- SV-SNN leads on all three "unfavorable" cases with 1/10–1/25 the parameters and 13–100× better L2.
- Honest costs: non-separable problems require **N ≥ effective separation rank** (Q1 uses N = 16); seed variance grows on hard cases; the grid must satisfy ≥3 points per wavelength (see E2).
- Supports the claim that the separable spectral architecture generalizes beyond training-distribution separable problems, with clear usage boundaries.
