# E7 分析报告：模态数 N 的缩放（含非可分离问题）

> 对应主题 **T7**，回应意见：**R5.4（N 如何影响精度/参数/时间、对非可分离的限制）、R8.5（达到目标精度所需 N）**。
> 数据：`saved_data/E7_results.json`；图：`figures/E7_mode_scaling.png`。

## 1. 设置
同一可分离 SV-SNN（每轴 K=32 频率、8000 epochs、Adam 1e-3、NC=100 网格、w_char=24π），模态数 \(N\in\{1,2,4,6,8,12,16\}\)，3 个随机种子，在两个问题上扫描：
- **separable**：Helmholtz κ=24π，\(u=\sin(\kappa x)\sin(\kappa y)\)（**秩-1**，理论上少量模态即可）；
- **nonseparable**：Poisson，\(u=\sum_{i=1}^{4}\sin(a_i x)\sin(b_i y)\)，\(a_i\ne b_i\)（**真·秩-4** 交叉耦合，需要更多模态）。

参数量随 N 线性增长：\(N\cdot(2\cdot2K+1)+N=N\cdot195\)（195 = 每模态两轴各 K 个 cos/sin 系数 + 偏置 + 模态系数）。

## 3. 结论与解读

### 3.1 可分离问题：少量模态即饱和
秩-1 解只需 N≈4 即达 ~0.03，之后提升缓慢（N=4→16 仅从 0.032 降到 0.018）。**对可分离问题，N=4–6 已是性价比拐点**，继续增大 N 主要增加参数与时间、精度收益递减。

### 3.2 非可分离问题：N 必须 ≥ 解的"分离秩"（关键，回应 R5.4）
非可分离秩-4 解上出现**清晰的阈值现象**：
- N=1,2（< 秩）：L2 高达 **0.90、0.78**（根本无法表征交叉耦合）；
- **N=4（= 秩）：L2 骤降到 0.124**（10× 改善）；
- N≥8：收敛到 ~0.03，与可分离问题相当。

这定量回答了 R5.4 关于"非可分离的限制"：**SV-SNN 通过增大 N 逼近任意函数（CP/分离秩展开），但 N 必须不小于目标解的有效分离秩**。这是方法的明确适用边界与处方——并非"无法处理非可分离"，而是"需要足够的模态数"。

### 3.3 算力随 N 的缩放
- **参数**：严格线性 \(195N\)（远小于同精度 PINN 的数万参数，见 E1/E6）。
- **时间**：近似线性（2.7s@N=1 → 23.7s@N=16），因可分离网格评估为 \(O(N\cdot N_c)\)，无平方爆炸。

### 3.4 达到目标精度的 N 处方（回应 R8.5）
| 目标 L2 | separable 所需 N | nonseparable(秩-4) 所需 N |
|---|---:|---:|
| ~0.1 | 1–2 | 4 |
| ~0.05 | 4 | 6 |
| ~0.03 | 4–6 | 8 |
| <0.02 | 16 | 16 |

**实用准则**：N 取"预估分离秩 + 余量（×2）"；可分离/低秩问题用 N=4–6，高秩/强耦合问题用 N=8–16。

## 4. 对应回复要点
- **R5.4（N 的影响与非可分离限制）**：给出 N–精度–参数–时间四维缩放；非可分离问题存在"N≥分离秩"的清晰阈值（N=4 处 10× 跃变），明确了方法适用边界与扩展方式。
- **R8.5（达到目标精度的 N）**：提供 N 处方表，参数随 N 线性、时间近线性，无平方爆炸，扩展性良好。
