# E7 — Mode Count (N) Scaling, Including Non-Separable Problems

**Purpose.** Sweep the modal count N on a rank-1 separable Helmholtz problem and a rank-4 non-separable Poisson problem to quantify accuracy/parameter/time scaling and provide a practical prescription for choosing N.

**Reviewer comments addressed.** R5.4 (effect of N and non-separable limits) and R8.5 (N needed for a target accuracy).

## Setup

| Item | Detail |
|------|--------|
| Model | K = 32 freqs/axis, 8000 epochs, Adam (lr = 1e-3), `NC = 100`, `w_char = 24π` |
| N values | {1, 2, 4, 6, 8, 12, 16}; params = 195·N |
| Separable | Helmholtz κ = 24π, rank-1 |
| Non-separable | Poisson, sum of 4 `sin(aᵢx)sin(bᵢy)`, rank-4 |
| Seeds | 3 |

## Key results

| N | Params | Separable L2 | Non-separable L2 | Time (s) |
|--:|-------:|-------------:|-----------------:|---------:|
| 1 | 195 | 0.133 | 0.896 | 2.7 |
| 2 | 390 | 0.093 | 0.780 | 3.7 |
| 4 | 780 | 0.032 | 0.124 | 6.5 |
| 6 | 1170 | 0.028 | 0.069 | 8.9 |
| 8 | 1560 | 0.037 | 0.034 | 11.3 |
| 12 | 2340 | 0.029 | 0.035 | 17.0 |
| 16 | 3120 | **0.018** | **0.030** | 23.7 |

Prescription for a target L2:

| Target L2 | Separable N | Non-separable (rank-4) N |
|-----------|------------:|-------------------------:|
| ~0.1 | 1–2 | 4 |
| ~0.05 | 4 | 6 |
| ~0.03 | 4–6 | 8 |
| <0.02 | 16 | 16 |

## Conclusions

- Separable rank-1 problems saturate at N ≈ 4–6 (~0.03 L2); further gains are diminishing.
- Non-separable rank-4 problems show a sharp threshold: N < 4 fails (L2 0.78–0.90), N = 4 drops to 0.124, and N ≥ 8 reaches ~0.03 — N must meet or exceed the effective separation rank.
- Parameters and training time scale **linearly** with N (2.7 s at N = 1 to 23.7 s at N = 16).
