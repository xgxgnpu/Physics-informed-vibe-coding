# E1 — Fair and Complete Baseline Comparison

**Purpose.** Provide a strictly budget-matched comparison of accelerated SV-SNN against SPINN, SIREN, FourierPINN, vanilla PINN, and a classical Fourier spectral reference on the 2D Helmholtz equation, where every neural baseline is given the *same* multilevel frequency prior as SV-SNN. This isolates the contribution of the architecture from the contribution of frequency information.

**Reviewer comments addressed.** R3.1, R5.2, R7.3, R5.7, R9.5, R3.4 (fair comparison, compute reporting), and R5.3/R9.1 (novelty vs classical spectral methods).

## Setup

| Item | Detail |
|------|--------|
| PDE | 2D Helmholtz: `-Δu - κ²u = f`, homogeneous Dirichlet |
| Exact solution | `u = sin(κx)·sin(κy)`, with `κ = 24π` and `κ = 48π` |
| Domain | `[0,1]²` |
| Training | 10,000 epochs, Adam (lr = 1e-3), single GPU (JAX) |
| Methods | SV-SNN (accelerated), SPINN, SIREN, FourierPINN, PINN, classical sine Galerkin |
| Fairness | All neural baselines use the same `sample_frequencies(·, w_char=κ)` prior as SV-SNN |
| Seeds | 5 per learned method (best relative L2, mean ± std) |

## Conclusions

- With identical frequency priors, SV-SNN wins by ~19× (κ = 24π) and ~110× (κ = 48π) over the best neural baseline, using 1–2 orders of magnitude fewer parameters.
- The advantage comes from the separable spectral architecture, not from exclusive access to frequency information.
- A classical spectral Galerkin solver reaches machine precision (~1e-13) on this perfectly separable problem; SV-SNN's value lies in harder geometries, variable coefficients, and nonlinear problems (see E8, E10, E14).
