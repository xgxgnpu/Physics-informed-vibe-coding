# E13 — Boundary Layer / Singular Perturbation

**Purpose.** Honestly assess SV-SNN on sharp boundary-layer (singular-perturbation) problems where global spectral bases are expected to struggle, and contrast it with FourierPINN and vanilla PINN.

**Reviewer comments addressed.** R5.6 (boundary layers), R9.4 (non-smooth/local gradients), R1.4 / R10.3 (limitations).

## Setup

| Item | Detail |
|------|--------|
| Solution | `u(x,y) = g(x)·sin(πy)` with an exponential boundary layer at x = 1, width ~ε |
| PDE | Poisson `-Δu = f` |
| ε values | {0.05, 0.02, 0.01} |
| Methods | SV-SNN (2322) vs FourierPINN (66177) vs PINN (50049) |
| Config | `w_char ≈ 1.2/ε`, 8000 epochs, BC weight 10 |
| Seeds | 3 (report gives mean, min, std) |

## Key results

Best relative L2, mean (min):

| ε | **SV-SNN** (2322) | FourierPINN (66177) | PINN (50049) |
|--:|------------------:|--------------------:|-------------:|
| 0.05 | 0.521 (0.266), std 0.32 | 0.242 (0.223) | **0.150** (0.142) |
| 0.02 | 0.692 (**0.027**), std 0.81 | 1.280 (1.165) | 1.218 (0.873) |
| 0.01 | 2.073 (1.207), std 0.62 | **0.900** (0.776) | 5.901 (1.020) |

Training time: SV-SNN ~10 s, FourierPINN ~13 s, PINN ~15 s.

## Conclusions

- Very thin layers (ε ≤ 0.01) fail for **all** methods (L2 ≈ 0.8–5.9): global Fourier bases face Gibbs ringing and a stiff source `f ~ ε⁻²`.
- At ε = 0.02, SV-SNN's best seed reaches 0.027 while baselines fail (mean > 1), showing expressivity but high seed variance (std 0.32–0.81).
- At ε = 0.05, the tanh PINN is most robust (0.150). This is a stated limitation; remedies include coordinate stretching, domain decomposition, and residual normalization.
