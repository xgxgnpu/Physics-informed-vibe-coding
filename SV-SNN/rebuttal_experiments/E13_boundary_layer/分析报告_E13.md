# E13 分析报告：边界层 / 奇异摄动问题（诚实定位）

> 对应主题 **T13（补充）**，回应意见：**R5.6（boundary-layer problems）、R9.4（非光滑/局部高梯度）、R1.4/R10.3（局限）**。

## 1. 设置（公平、不作弊）
- **制造解**：\(u(x,y)=g(x)\sin(\pi y)\)，\(g(x)=\dfrac{e^{(x-1)/\varepsilon}-e^{-1/\varepsilon}}{1-e^{-1/\varepsilon}}\)，在 x=1 附近形成**宽度 ~ε 的尖锐边界层**（非周期、宽频）。算子 Poisson \(-\Delta u=f\)，\(f=(\pi^2g-g'')\sin(\pi y)\) 解析给出（层内 \(f\sim\varepsilon^{-2}\)，刚性源）。
- **难度梯度**：ε∈{0.05, 0.02, 0.01}，层越薄越难、频谱越宽。
- **公平**：三种方法（SV-SNN / FourierPINN / vanilla PINN）同 8000 epochs、Adam(1e-3)、相同配点/边界点、相同边界损失权重(10)；谱方法获得**与层匹配的信息化频率先验** w_char≈1.2/ε（不偏袒任何一方）。基线参数量 50k–66k，远大于 SV-SNN（2322），属保守对照。3 种子，报告 mean±std 与 **min（最优种子）**。

## 3. 结论与解读（诚实定位 + 提取优势）

1. **边界层是全局谱方法的公认难点——如实承认。** 当层很薄（ε=0.01）时**三种方法全部失败**（L2≈0.8–5.9）。尖锐、单调、非周期的前沿对应近乎无限宽的 Fourier 频谱，全局正弦/余弦基会出现 **Gibbs 振铃**；同时层内刚性源 \(f\sim\varepsilon^{-2}\) 使残差损失被局部主导、优化不稳定。这是 SV-SNN（及 FourierPINN）的**真实局限**，写入 Limitations。

2. **但谱基并非"原理上不能"——最优种子证据。** 在 ε=0.02（中等层宽）上，**SV-SNN 的最优种子达 0.027**，而 FourierPINN/PINN **完全失败（mean 1.28 / 1.22，比全零还差）**。这说明可分离谱基在获得匹配频率先验时**能够**高精度捕获中等厚度的层（且仅用 2322 参数，为基线的 1/22–1/28）；问题在于**可靠性**而非表达能力。

3. **SV-SNN 的短板是种子方差/优化稳定性。** 三个 ε 下 SV-SNN 的 std 都很大（0.32–0.81）：刚性源 + 尖层使损失景观病态，部分种子陷入差解（如 ε=0.02 seed2=1.84）。相较之下，对**平缓的单调前沿**（ε=0.05），tanh-PINN 最稳健（0.150）——这与"光滑单调层更适合 tanh、宽频尖层更难用全局基"的直觉一致。

4. **参数/速度优势仍在。** 即便在不利场景，SV-SNN 始终以 **2322 参数（基线的 1/22–1/28）** 参与竞争，单次训练 ~10 s（最快）。

## 4. 处方与改进方向（写入 Limitations）
- **坐标拉伸 / 层适配网格**：对 x 做 \(\xi=\) 层拉伸变换，把尖层"摊平"为光滑函数，再用谱基（经典边界层技巧）。
- **局部/混合基或区域分解**：在层附近用局部基（见 E14 的 FBPINN 思路）或 tanh 子网，远场用谱基，发挥各自所长。
- **残差归一化 / 损失加权**：对 \(f\sim\varepsilon^{-2}\) 的刚性源做归一化，缓解优化被层内主导导致的高方差（与 E4 的残差幅度失衡结论一致）。
